# PNC-SLAM Telemetry Fault Taxonomy & Reproducible Examples

Use this reference alongside [SKILL.md](../SKILL.md) to map common autonomous-driving PNC & LiDAR-SLAM symptoms onto standard topic roles and reproducible synthetic bags generated by `fault_sim_kit`.

> **Scope Note**: This reference intentionally documents conceptual telemetry relationships and public topic roles without hardcoded vehicle thresholds, private calibration rules, or automated causal engine arbitration rules.

---

## 1. Conceptual Telemetry Relationships by Fault Category

| Category | Standard Topic Roles Involved | What Thin Inspection Checks | Unverified Limitations |
|---|---|---|---|
| **Localization Jump vs Odometry Mismatch** | `tf`, `odom_pose` (or `chassis_feedback`), `imu`, `localization_pose` | Presence of all competing sensor/pose roles, valid `header.stamp`, sample `frame_id` / `cov_trace` / angular velocity sign conventions | Requires calibrated multi-topic time alignment and domain kinematic analysis to distinguish backend relocalization jumps from odometry scale/slip |
| **Trajectory Freeze / Jump / Obstacle Recovery** | `local_plan`, `control_cmd`, `laser_scan`, `diagnostics`, `solver_status` | `local_plan` availability, trajectory point counts in sampled paths, diagnostic message strings, `laser_scan` valid beam summary | Cannot attribute downstream braking to an obstacle or solver issue from `sample_mapped_signals` alone without full-stream precedence & curvature analysis |
| **Control Actuation Delay & Oscillation** | `control_cmd`, `odom_pose`, `imu`, `local_plan` | Command vs feedback role coverage, sample rates, jitter warnings, bounded sample twist/steering values | Estimating pure actuation delay or periodic oscillation requires calibrated closed-loop time-series correlation |
| **Frame Drops & Timestamp Integrity** | `odom_pose`, `laser_scan`, `imu`, `localization_pose` | `large_gap_detected`, `monotonic_violation`, `zero_log_timestamp`, `zero_header_stamp_in_sample`, neutral `observed_header_minus_log_ms` | `observed_header_minus_log_ms` alone cannot separate clock skew from recording/transport buffering delay |
| **Multi-Symptom / Incomplete Bags** | All mapped roles | Missing required roles (`missing_roles`) and invalid header stamps prevent overconfident system-health claims | Missing `imu` / `local_plan` or zero stamps should remain reported as unresolved limitations |

## 2. Standard Topic Mapping Profiles

- **Nav2 Default** (`configs/topic_map.nav2.yaml`, FLU / rad):
  - `odom_pose` (`/odom`), `localization_pose` (`/amcl_pose`), `tf` (`/tf`), `local_plan` (`/plan`), `control_cmd` (`/cmd_vel`), `imu` (`/imu/data`), `laser_scan` (`/scan`), `diagnostics` (`/diagnostics`), `solver_status` (`/planning/solver_status`).
- **Autoware Universe** (`configs/topic_map.autoware.yaml`, FLU / rad):
  - `localization_pose` (`/localization/kinematic_state`), `ndt_pose` (`/localization/pose_estimator/pose_with_covariance`), `tf` (`/tf`), `local_plan` (`/planning/scenario_planning/trajectory`), `control_cmd` (`/control/command/control_cmd`), `chassis_feedback` (`/vehicle/status/velocity_status`), `imu` (`/sensing/imu/tamagawa/imu_raw`), `laser_scan` (`/sensing/lidar/scan`), `diagnostics` (`/diagnostics`), `solver_status` (`.../processing_time_ms`).

## 3. Reproducible Synthetic Example Index (`fault_sim_kit`)

Generate all 10 synthetic MCAP example bags and manifest (`data/golden/golden_truth.json`) locally with:

```bash
env -u PYTHONPATH uv run python -m fault_sim_kit.generator
```

| Scenario Directory | Synthetic Phenomenon (For Workflow & Inspection Practice) |
|---|---|
| `nav_baseline` | Nominal baseline closed-loop trajectory with complete Nav2 topics |
| `case_01_tf_jump` | Synthetic `map -> odom` step jump & localization covariance spike |
| `case_02_ctrl_delay` | Synthetic actuation delay on `/cmd_vel` causing oscillatory tracking |
| `case_03_time_desync` | Synthetic `/scan` header drift paired with a transient scan frame drop |
| `case_04_planner_stuck` | Synthetic obstacle intrusion in `/scan` followed by plan freeze & BT recovery |
| `case_05_odom_slip` | Synthetic wheel-odometry scale mismatch during curved motion |
| `case_06_healthy_sharp_turn` | Nominal sharp-turn deceleration profile (negative false-alarm example) |
| `case_07_mixed_slip_plus_ctrl_delay` | Overlapping synthetic wheel-odometry mismatch and late control lag |
| `case_08_missing_imu_and_scan` | Example omitting `/imu/data` and `/scan` to practice `missing_roles` gating |
| `case_09_invalid_zero_stamps` | Example with zeroed `header.stamp` fields on `/plan` & `/amcl_pose` to practice timestamp warnings |
